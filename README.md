# 📝 Not Defteri Uygulaması- NOTEBOOK

Windows Forms ile geliştirilmiş zengin metin editörü uygulaması.

## ✨ Özellikler

- **Metin Formatlama**: Yazı tipi, boyut, kalın, italik, altı çizili
- **Renk Seçimi**: Yazı rengi ve arka plan rengi
- **Tema Desteği**: Açık, koyu ve özel tema seçenekleri
- **Dosya İşlemleri**: Aç, kaydet, PC'de aç
- **Türkçe Karakter Desteği**: UTF-8 encoding ile tam Türkçe desteği
- **RTF Desteği**: Zengin metin formatı (RTF) dosyaları

## 🚀 Kullanım

### Gereksinimler
- Windows 10/11
- .NET Framework 4.8
- Visual Studio 2022 (geliştirme için)

### Kurulum

1. Projeyi klonlayın:
```bash
git clone https://github.com/kullaniciadi/NoteBook.git
```

2. Visual Studio 2022'de `NoteBook.sln` dosyasını açın

3. **F5** tuşuna basarak çalıştırın veya **Build > Build Solution** ile derleyin

### Çalıştırma

- Visual Studio'dan: **F5** tuşu
- Doğrudan: `NoteBook\bin\Debug\NoteBook.exe` dosyasını çalıştırın
- Batch dosyası: `NotDefteri_Baslat.bat` dosyasına çift tıklayın

## 📋 Menü Özellikleri

### Dosya Menüsü
- **Aç**: Mevcut dosyayı aç (TXT, RTF)
- **Kaydet**: Dosyayı kaydet
- **PC'de Aç**: Dosyayı varsayılan uygulamayla aç

### Tema Menüsü
- **Açık Tema**: Beyaz arka plan
- **Koyu Tema**: Koyu gri arka plan
- **Özel Tema**: Renk seçiciyle özel tema oluştur
